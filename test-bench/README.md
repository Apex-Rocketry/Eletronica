# Bancada de Testes Estáticos (Test Bench / DAQ)

Hardware, firmware e scripts voltados para ensaios em solo, aquisição de dados (DAQ) e testes estáticos de motores.

## O que armazenar aqui
- Firmware de aquisição de dados e leitura de células de carga / transdutores de pressão;
- Circuitos de condicionamento de sinal e instrumentação;
- Scripts de calibração, filtragem e pós-processamento dos dados coletados nos ensaios.

## Boas Práticas
- Registre sempre os fatores de calibração e a taxa de amostragem utilizados em cada versão do sistema.
